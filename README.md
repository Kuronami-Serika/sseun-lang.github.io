# SSEUN-LANG
사랑은 달다 그리고 너무 달면 쓰다. 결국 아맛나

## 실행

Windows에서는 `run-sseun.cmd`를 더블클릭하면 실행이 끝난 뒤에도 결과를 볼 수 있습니다.
IDLE에서는 **File → Open**으로 `sseun.py`를 편집기에 열고 F5를 누르세요.
같은 폴더의 `example.sseun`이 있으면 실행하고, 없으면 `example.txt`를 실행합니다.
예제를 수정할 때는 UTF-8로 저장하세요.

터미널에서 다른 쓴랭 파일을 실행하려면 파일 이름을 인자로 넘기세요.

```powershell
python sseun.py example.txt
```
